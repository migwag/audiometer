# Extended-Range Audiometer

A browser-based pure-tone hearing self-test from 125 Hz to 20 kHz. It uses the modified Hughson-Westlake procedure, plots an audiogram, and builds a hearing-compensation EQ (Equalizer APO preset, band list, CSV curve) for audio monitoring.

**Not a medical diagnosis.** Results depend on volume calibration and on the frequency response of the headphones used.

Live page: https://migwag.github.io/audiometer/
